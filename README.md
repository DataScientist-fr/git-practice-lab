# Git Practice Lab

Bienvenue dans **Git Practice Lab**.

Ce dépôt est un petit espace d'entraînement pour pratiquer Git et GitHub.

L'objectif est de s'exercer à :

- cloner un dépôt ;
- créer une branche ;
- modifier un fichier ;
- faire un commit ;
- pousser une branche ;
- créer une pull request.

Ce dépôt ne contient pas de vrai projet applicatif.

Il sert uniquement à manipuler Git dans un environnement simple et sans risque.

## Exercice

Votre mission est simple :

1. Créez une branche.
2. Ouvrez le fichier `CONTRIBUTING.md`.
3. Ajoutez votre prénom.
4. Ajoutez éventuellement un petit message.
5. Faites un commit.
6. Poussez votre branche.
7. Ouvrez une pull request.

Bon entraînement !
